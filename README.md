# 全身トラッキング・フェーズ2
映像から全身133点と両手の詳細を推定し、校正した2視点から3Dを復元するPoC。モデルが返す信頼度、多視点の幾何整合性、時間補完、欠測を区別する。

- 作業ブランチ: https://github.com/DaisukeDaisuke/Wholebody-test/tree/phase2/732e048e

## 使い方
1. PCのChrome/Edgeで開き、全身モデルを選んで「モデルを読み込む」を押す。既定はRTMW-L FP32。初回は約229MBの全身モデル、約4MBの手モデル、約40MBの人物検出モデルと推論runtimeを取得する。
2. 入力Aへローカル動画または写真を選び、推論を開始する。映像上のドラッグで人物ROIを指定できる。自動検出では最大領域の1人を選び、前回の人物枠との重なりで追跡する。
3. 単眼3DはRTMW3D-Lを選ぶ。相対奥行きと身長からの骨長priorで距離を推定する。画角だけの状態は未実測の暫定値であり、正確なメートル値として扱わない。
4. 2視点では入力A/Bへ同じ人物の異なる方向の映像を入れる。「2視点の校正」で同じ床矩形を同順に4点クリックし、実寸と内部パラメータを入力する。実測Kがない場合は暫定校正として扱う。
5. 録画を使う場合は動画Bの時間差を入力し、同時刻対応を確認する。WebRTCでは利用可能なcaptureTimeを用い、得られない場合は表示時刻による暫定推定へ分ける。
6. 「精度と記録」から姿勢・時刻・校正・処理時間をJSON保存する。元映像は含まない。
## ローカル配信とLANカメラ
Node.js 22以降を使用する。npm依存はない。
```sh
node server.mjs
```
この場合は `http://127.0.0.1:8080/` のPC内配信。スマホからの撮影には端末が信頼する証明書を指定する。
```sh
node server.mjs --cert /absolute/path/server-cert.pem --key /absolute/path/server-key.pem --host 0.0.0.0 --port 8443
```
PCと撮影ページで同じサーバーURL・起動時に表示された接続トークン・ルーム名を入力する。PCで「受信を待つ」、スマホで「カメラを開く」→「PCへ接続する」を押す。カメラA/Bを別々に割り当てる。端末の証明書信頼やLAN到達性は使用環境側で必要。SitesのHTTPS撮影ページでも、ローカルサーバーの証明書を信頼する必要がある。
接続情報は認証付きHTTPSの短いポーリングで交換し、映像はブラウザ間のWebRTCへ直接流す。サーバーを使わずSDPの接続情報・応答を手動交換する経路もある。外部STUN/TURNは使用せず、host候補以外を拒否する。アプリの通信記録はOS全体のパケット監査やCodex sandboxの実機検証の代替ではない。
## 実装範囲
- 動画・画像・PCカメラ・2台のLAN撮影端末。
- 元フレームを1度固定し、同じ画像から全身と手を推論する。別時刻の画像へ手のROIを適用しない。
- RTMPose-S/T、RTMW-L、RTMW3D-LのFP32を選択可能。モデルはrevisionとSHA-256を固定する。
- MediaPipe手モデルによる回転ROIの21点推論。画像外・低presence・手首不整合では元点を維持する。presenceを指ごとの可視確率にはしない。
- 2視点の時刻差、再投影誤差、視線交角、基線長を確認した三角測量。未校正・未同期の暫定推定を分離する。
- 短時間の速度外挿と骨長・掌座標による補完。再観測がない限り寿命を延長しない。
- 足首・踵・母趾先・小趾先から足の向きと甲の代理位置を生成。5本の足指の独立した関節運動は出力しない。
- SteamVR/VMT/VRChat送出と追加カメラ購入はフェーズ3であり、今回の実装対象に含めない。
## 精度評価
評価はGitHub Actionsの `Actual-image pose evaluation` で実行する。ローカルのモデル推論・ブラウザ自動テストは実行していない。CIの構文・幾何検査と、画像/動画の推論精度を分けて記録する。
初回はCOCO-WholeBody公式サンプル4画像・12人。人物の正解BBoxから推論するため、人物検出器の性能は含まない。RTMW-Lは手の平均誤差4.084px、手の拡大推論追加は3.949px。全身モデルの高いscoreだけでは遮蔽を検出できず、隠した手では低精度である。
初回とは別の64人のholdout評価と、Panopticの同期2視点・3D正解座標を用いる評価を追加する。公開する数値は該当Actions run/commit/データ条件に結び付ける。合成幾何の誤差を実機カメラの精度と呼ばない。GPU60fpsやユーザー端末での精度は未実測。
