# Wholebody Studio の使い方

## まず1本の映像で始める

1. PCでアプリを開き、入力Aの **「動画を選ぶ」** または **「PCカメラ」** を押します。
2. **「人物を自動検出」** は既定でONです。別の人を追ったら **「人物を囲んで選ぶ」** を押し、映像上で追いたい人の全身をドラッグして囲みます。手動で選んだ範囲が優先されます。**「解除」** で自動選択へ戻ります。自動検出がOFFの場合は全画面から推定します。
3. 全身モデルを選び、**「モデルを読み込み、開始」** を押します。手指は **「手を切り出して再推論」** をONにすると、元の映像から手を拡大して処理します。
4. 全身表示と手足の拡大表示を確認します。3D表示はドラッグで回転、スクロールで拡大できます。人物検出のON/OFFを変更するときは、推論を **「停止」** してから変更し、再開します。

**「足先を位置関係で補正（比較）」** は既定でOFFです。比較したい場合だけ推論を停止してONにし、再開します。足の候補と全身の足首の位置関係が合う場合に補正します。通常の全身推定と同じ映像で見比べられます。

## スマホを入力A・Bのカメラにする

PCとスマホを同じWi-Fiに接続します。スマホは撮影と送信、PCは推論を担当します。

1. PCの入力Aで **「スマホ接続」→「招待を作る」→「招待リンクをコピー」** を押し、そのリンクをスマホで開きます。これがPCからスマホへ渡す招待SDPです。
2. スマホで背面・前面カメラを選び、**「カメラを開始して接続」** を押してカメラ利用を許可します。リンクに招待が入っていない場合は、PCの招待コードを **「PCからの招待」** に貼り付けます。
3. スマホの **「応答をコピー」** を押し、PCの同じ入力Aの **「スマホの応答」** に貼り付けて **「応答を適用」** を押します。これがスマホからPCへ返す応答SDPです。接続できると入力Aに映像が出ます。
4. 2台目は入力Bで新しく招待を作り、もう1台のスマホで同じ往復を行います。Aの応答をBへ貼り付けることはできません。
5. 2台で同じ人物を、違う方向から撮影します。必要ならA・Bそれぞれで人物を囲みます。スマホの撮影画面は開いたままにします。

接続が失敗する場合は、同じWi-Fiで端末間の通信が許可されているかを確認し、招待を作り直します。映像用の中継サーバーは使いません。

## 同時撮影した2本の動画を合わせる

1. 入力A・Bに、同じ人物を別方向から同時撮影した動画を読み込みます。1本を複製しても2視点にはなりません。
2. **「2本を一時停止」** を押し、各動画の再生位置を動かして同じ瞬間を表示します。拍手で手が触れる瞬間など、両方から分かる動作を目印にします。
3. **「現在の表示フレームを同時刻に合わせる」** を押します。動画Bの時刻補正が入り、対応時刻の確認欄がONになります。
4. **「2本を同時に再生」** を押します。Aの時刻に合わせてBを移動してから再生します。ずれが続く場合は再び一時停止して対応時刻を合わせます。

**「2視点3D」** は、時刻と校正の条件を満たし、2台から3D位置を求められた点があるときに出ます。使えない場合は **「動画の対応時刻が未確認」**、**「時刻差＋誤差 …」**、**「カメラ校正なし」** など、理由を同じ場所に表示します。時刻の理由なら対応フレームを合わせ直し、校正の理由なら次の手順で校正します。ライブ映像の **「撮影時刻が不確か」** は、撮影時刻が取れないか、その精度が足りない状態です。

## 空間位置を校正する

### 保存した校正JSONを使う

**「尺度と校正」→「校正JSONを読む」** で、このカメラ配置に対応するファイルを読み込みます。カメラのIDは入力Aが `a`、入力Bが `b` です。2台の校正は同じ原点・座標軸にそろえます。カメラの位置・向き・レンズ設定を変えた場合は校正し直します。

身長を尺度に使う場合は、画面の **「身長 [m]」** を入力し、本人の実測値なら **「身長は本人の実測値」** をONにします。校正JSONに有効な身長と確認状態が保存されていれば、この2項目も復元します。

### 既知の長方形の4点を選ぶ

1. 実寸の分かる長方形の板を垂直に固定し、2台から同じ板が見えるようにします。板の左下が原点、板の右方向がX、上方向がYになります。両カメラで、板の同じ4隅を対応させます。
2. **「同じ平面の4点で校正」** を開き、入力Aを選びます。板の横幅・縦幅をメートルで入力し、このカメラ・この解像度の `fx / fy / cx / cy` と歪み係数を入力します。これらを事前校正してある場合に **「Kと歪みはこの解像度で事前校正済み」** をONにします。4点選択だけでレンズの内部校正は行いません。
3. **「4点を選ぶ」** を押し、止まった映像で板の **左上 → 右上 → 右下 → 左下** を順にクリックし、**「校正を適用」** を押します。
4. 入力Bでも繰り返します。内部パラメータと歪みはBのカメラの値に入れ直し、板は動かさず、Aと同じ4隅を指定します。完了した設定は **「保存」** で残せます。

**「仮のカメラ配置」** から入力した設置位置・画角は推定用です。校正済みの3D推定とは表示を分けます。**「校正の座標系が不一致」** と出たら、2台を同じ板・原点・座標軸で校正してください。

## 推定・補完・欠測の読み方

| 表示 | 意味 |
|---|---|
| 校正済み2視点の3D推定 | 時刻の対応した2台の観測から位置を求めています。 |
| 仮配置による2視点推定 | カメラ配置に仮の値が含まれます。 |
| 単眼・人体モデルによる推定 | 1視点と身体の形・過去の姿勢から奥行きを推定しています。 |
| 遮蔽中の予測・補完 | 今は直接観測できず、直前の動きや周囲の関節から補っています。時間がたつと確かさを下げます。 |
| 欠測 | 位置を表示できる根拠が足りません。 |
| 絶対位置は未校正 | 骨盤を基準とする相対表示です。骨盤X/Y/Zの `—` は距離の計測値ではありません。 |

骨盤位置にメートル表示が出ても、隣の説明が単眼推定なら推定値として読みます。**「現在距離を固定」** は距離の基準を検証するときだけ、0.1 mより大きく30 m未満の数値を入力し、**「基準位置の検証中だけ距離を固定」** をONにします。空欄や範囲外では固定できません。固定中は単眼の前後移動を推定しないため、通常の動作追跡ではOFFにします。

手は左右21点です。足は母趾・小趾・踵と身体側の足首から甲の向きを求めます。5本の足指の補完形状は、各指の曲がりを映像から個別に測った値ではありません。

**「Actions実測」** の先頭には、調整に使わなかった固定標本での結果を表示します。主表は人物の自動検出から始めた通常画像・手の遮蔽・足の遮蔽の成績です。正解の人物枠を与えた参考値と、調整に使った標本の診断は折りたたみで分けています。件数と採点した点数は配信された結果の実数を使い、まだ完了していない項目は未評価と表示します。

**「観測を採用するスコア」** は、点を使うかどうかの基準です。可視性や正解の確率を示す数値ではありません。

## 結果の保存とオフライン利用

**「計測JSONを書き出す」** で直近1,800回分の2D観測と3D推定、校正、処理時間を保存します。映像そのものは含みません。A/Bは各観測の入力IDで区別され、人物の選択方法、観測できた点、補完された3D点を追えます。最新姿勢 `latestPose` とその時刻も保存するので、受信停止後に予測・保持・欠測へ進んだ現在の状態も残ります。

オフラインで使う場合は、オンラインのうちに使うモデルを読み込み、**「保存済みデータで実行」→「オフライン準備」** を行います。その後 **「保存済みデータだけで実行（閉域）」** をONにし、準備したモデルで推論を再開します。再読み込みを求める表示が出た場合は、ページを再読み込みしてからONにします。**「通信を確認」** は、このページの読み込みとスマホとの接続経路を確認する機能です。
