# 固定32画像による未使用標本検証

**結論は、Hand5選択採用を既定ON、FOCUS足補正を既定OFFとする。** 手の通常画像での改善は小さく、隠した手指のPCK改善は確認できなかった。足補正は、4画像の開発用診断では改善した方式も、この32画像では通常・遮蔽の両方で悪化した。判定閾値、モデル、blend係数、画像選択は結果を見て変更していない。

実行は[GitHub Actions run 41378750685](https://github.com/DaisukeDaisuke/Wholebody-test/actions/runs/41378750685)、評価対象commitは`7e3bf03021d7b2131ec7fc7b3b4583508b8ad6e9`、結果作成時刻は2026-11-02 02:41:26 UTC。以下の数値は同runの`holdout-report.json`、`holdout-predictions.json`、`holdout-selection.json`から集計した。推論はActionsのCPUで実行し、ローカルやブラウザで追加のモデル実行は行っていない。

## 固定した検証条件

COCO-WholeBody val v1.0の公式注釈と、同一hashのミラーを使用した。開発に使った画像ID `785,40083,196141,197388`を全て除外し、各画像で最大の有効な身体BBoxを持つ人物を先に確定。その人物に採点可能な手・足注釈がある655候補から、`SHA256(seed:imageId:annotationId)`昇順の32画像を選んだ。画像取得不能時の入替はせず、今回の32画像は全て取得できた。[固定選択と評価の実装](https://github.com/DaisukeDaisuke/Wholebody-test/blob/7e3bf03021d7b2131ec7fc7b3b4583508b8ad6e9/evaluation/holdout-evaluate.py)、[COCO-WholeBody公式配布元・利用条件](https://github.com/jin-s13/COCO-WholeBody)。

人物検出BBox経路は、YOLOX-tinyが出したperson候補から最大のBBoxを選ぶ。正解人物BBoxは推論や対象選択に使わない。別人物を選んだ結果や未検出も採点に残す。正解BBox経路は人物選択の影響を調べるreferenceであり、出荷経路の実測値とは混ぜない。GTは人工maskの位置決めと採点にも使うが、手ROIやFOCUSの候補採用に渡さない。

PCK@.2は、身体では人物BBoxの長辺、手では注釈手BBoxの長辺、足では同じ足の注釈点の最大広がりの20%以内を正解とする。PCK@.1はその10%。部位間の許容画素誤差は同じではない。以下の平均・p95は画素単位で、未検出の無限大誤差は画素誤差の集計に入らない一方、PCKでは失敗に数える。画像数は32であり、1,132個の手点を独立な1,132標本とは扱わない。

## 人物選択の診断

固定対象のGTを使って選び直すことはしていない。推論後に、予測された身体点との正規化距離が最小の注釈人物と、選んだ検出BBoxとのIoUが最大の注釈人物を確認した。以下の取り違え例では両方の診断が同じ別人物を指した。これはこの標本内の対象選択診断であり、動画での人物ID維持率や一般的な再同定精度ではない。

|条件|対象と一致する診断|別人物に一致する診断|人物未検出|別人物となった画像ID|
|---|---:|---:|---:|---|
|clean|29/32（90.6%）|3/32（9.4%）|0/32|33104、578489、540414|
|hand mask|27/32（84.4%）|4/32（12.5%）|1/32（3.1%）|33104、34139、578489、540414|

cleanの画像33104では、選択BBoxと固定対象516849のIoUは0.156だが、別人物466638とは0.944。画像578489では固定対象1246823とのIoUが0で、別人物1316842と0.865。画像540414では固定対象2028895とのIoUが0で、別人物1754827と0.816だった。手・足maskでは画像34139も別人物へ変わる。手maskで未検出になった画像は213086。

身体のclean平均誤差は検出経路21.729px、正解BBox referenceでは4.998px、p95は150.100px対14.287pxだった。手や足を局所補正しても、別人物を選んだ入力そのものは修正できない。この差を専門モデルの成績に埋め込まず報告する。

## 画像ごとの改善と回帰

各画像を1単位として数えた。PCKは高い方、平均誤差は小さい方を改善とする。PCK同点でも平均誤差が動く場合がある。手maskで人物未検出の1画像はPCK同点の失敗で、平均誤差は比較不能として分けた。

FOCUS one2manyはcleanで21画像、foot maskで19画像の足点を変更した。変更した画像では、平均足誤差がcleanで15画像、foot maskで16画像悪化した。足の既定OFFは、一つの外れ値だけで決まった判断ではない。

正解BBox referenceでも、足blendのcleanはPCK改善3／同点22／悪化7画像、平均誤差は改善6／同点7／悪化19画像。foot maskではPCK改善1／同点20／悪化11画像、平均誤差は改善1／同点12／悪化19画像だった。

## 結果の適用範囲と保存内容

この32画像は当PoCの手・足の採用規則を調整した4画像から分離されている。上流モデルの学習やモデル選択にCOCO valが使われたかは除外確認できておらず、`trainingOverlapExcluded=false`のままとする。手足注釈のある最大人物を選ぶ標本であり、実利用映像全体を代表する抽出ではない。

身体・手・足のモデル出力は2Dで、この検証は3D精度、実動画の追跡、カメラ間の時刻同期、自然な長時間遮蔽からの復帰、ブラウザWebGPUでの速度を測っていない。COCO足点は片足の母趾先・小趾先・踵の3点であり、5本の足指の独立した関節の精度は未評価・未観測。足の甲や中間の足指関節列は幾何推定として区別する。各モデルのraw scoreは未校正で、可視確率・正解確率として解釈しない。

配布するものは`holdout-report.json`、`holdout-predictions.json`、`holdout-selection.json`と結果文書。元JPEGと人工mask画像は成果物に含めない。全32画像の選択ID、方法別数値、候補採用の記録はJSONに保存した。モデルと判定ルールをこの結果に合わせて再調整せず、手ON・足OFFの構成で公開する。
